## 🎮 About Me

I'm a software developer with a QA engineering background and a strong focus on **game development**. I build under the **Solim Studios** banner, currently shipping a mobile cat game in Unity called **Ctrl Cat Delete**.

During the day I work as an **SDET at CI&T**, doing backend automation with Karate and frontend automation with Playwright + Applitools. The rest of the time I'm in Unity, Blender, or building side tools that automate things that shouldn't have to be done manually.

- 🕹️ Main game engine: **Unity (URP, mobile-first)**
- 🧪 QA/Automation: **Karate, Playwright, Applitools, Selenium**
- 🎬 Exploring: **Blender, Unreal Engine, content creation**
- 🔧 Currently shipping: **Ctrl Cat Delete** (Unity, Android)
- 💡 Also building: **Clipperly** — an automated clip farming pipeline for Kick.com streamers
